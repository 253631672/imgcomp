# imgcomp

批量图片压缩，单文件，零依赖（只用到 `Pillow`）。最长边缩放 + 按目标体积二分找画质，保留目录结构，自动纠正 EXIF 方向。

Windows 和 macOS 都能跑。

## 为什么写这个

你手上有一批图要传平台 / 发给客户 / 放网页，单张几十MB，平台又卡体积上限。大多数在线压缩站要么要登录、要么一次只传几张、要么传上去就被压缩得糊掉。

这个脚本做的事很简单：**先按最长边缩小到合理尺寸，再在质量区间里二分，找到"刚好不超目标体积"的那个质量点**，不浪费一档画质。

## 用法

```bash
# 单张
python3 imgcomp.py 大图.jpg 输出/

# 一整个目录（300张）
python3 imgcomp.py ./原图 ./压缩后 --max-side 1600 --kb 200 --keep

# 转 WebP
python3 imgcomp.py ./原图 ./webp --kb 150 --format WEBP --keep

# 保留透明通道（PNG）
python3 imgcomp.py ./图标 ./png --format PNG --max-side 512
```

`example/batch.sh` 是一个可直接改路径就跑的批量示例（缩到最长边1600、单张300KB以内）。

## 参数

| 参数 | 默认 | 说明 |
|---|---|---|
| `src` | — | 输入文件或目录 |
| `dst` | — | 输出目录（不存在会自动建） |
| `--max-side` | 1600 | 最长边像素上限，小于这个值不放大 |
| `--kb` | 200 | 单张目标体积上限（KB） |
| `--format` | AUTO | AUTO / JPEG / PNG / WEBP。AUTO 会把带透明的 PNG 保留为 PNG，其余转 JPEG |
| `--keep` | 关 | 保留源目录层级 |

## 实测

| 场景 | 输入 | 输出 | 压缩率 | 耗时 |
|---|---|---|---|---|
| 300张 2600×1600 JPG | 257.6MB | 50.1MB | 81% | 43秒 |
| 10张 3900×2400 JPG | 18.3MB | 1.6MB | 91% | 6秒 |

质量落在 80–92 之间，肉眼看不出差异。

## 几个坑

1. **透明通道会丢**。转 JPEG 时透明会变成黑/白底，需要透明就加 `--format PNG` 或保留 AUTO（PNG 源文件会走 PNG）。
2. **不要指望它把质量很差的原图变好**。它只负责合适地降体积，不负责修图。
3. **`--kb` 太小学会导致糊**。1600宽的照片压到 80KB 以下，质量会明显掉。
4. 依赖只有一个：`pip install pillow`。不需要 numpy、不需要 ffmpeg。
5. `--keep` 关掉时同名文件会互相覆盖，多子目录批量时一定加 `--keep`。
